# ATD ThreadLock Capability Closure v0.1

## Purpose

Integrate OIC theorem consequences, bidirectional formal-gap closure, ThreadLock boundary handling, quantum/spectral invariants, SIM2XR-style projection/reconstruction, and PCSS proof-gated performance evidence into one fail-closed operational process.

## Core operator chain

ψ_final = A_exec ∘ I ∘ L ∘ K ∘ E(ψ_initial)

- E: exception/deadlock extraction
- K: theorem-consequence compilation
- L: logical novelty extraction
- I: institution synthesis
- A_exec: admissibility-gated execution

The capability layer additionally uses R for reverse reconstruction.

## Novelty predicate

A proposed capability K_n is a novelty candidate only when its declared scope supports:

K_n ∉ Closure_A(K_existing)

This is a novelty witness, not an automatic scientific-priority claim. Prior-art analysis remains separate.

## Constitutional Novelty Certificate

A CNC links:

1. source theorem/certificate
2. boundary/deadlock provenance
3. theorem consequence
4. novelty witness
5. institution manifest
6. forward quotient evidence Q
7. reverse reconstruction evidence Q_inverse
8. invariant evidence Omega (and declared S/Delta/Xi observables when applicable)
9. native performance X
10. formal Lean L
11. replay and provenance lineage

## Bidirectional formal-gap closure

A formal equivalence/reconstruction gap is closed only if both directions pass for the declared scope:

Q(e_c) = Q(e_b)

and

d(R(Q(e_c)), e_c) <= epsilon.

One direction never promotes the other.

## PCSS promotion

For speedup claims, promotion requires:

PUBLISH iff I ∧ R ∧ Q ∧ Q_inverse ∧ Omega ∧ X ∧ L

Any false or unknown required predicate results in quarantine.

## Recursive reuse

Verified primitives remain scope-bound. Reuse requires a valid instantiation followed by a fresh composed native run. Individual ratios are never multiplied to infer a composed speedup.

## Operational efficiency

The capability layer may cache a previously certified mapping:

(state signature, exception signature, theorem signature, scope signature)
→
(institution, certificate, replay, evidence class)

Reuse performs scope/assumption verification before execution and avoids unnecessary re-derivation.

## Exception-to-institution rule

A deadlock is represented as a first-class Boundary. Its theorem-supported consequences can generate a reformulation and a candidate institution. The candidate cannot become constitutional until bidirectional closure and the applicable PCSS gates close.

## Scope boundary

This specification does not claim that the supplied quantum work, speedups, or universal novelty are independently proven by this integration alone. It provides the mechanism by which such claims can acquire stronger evidence classes through explicit artifacts and verification.
